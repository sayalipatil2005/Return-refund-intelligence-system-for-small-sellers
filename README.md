# Return & Refund Intelligence System for Small Sellers

An academic team project developed to help small sellers manage return and refund operations.

## Project Overview
The system is designed to support return and refund management, including order identification and retrieval through QR codes.

## My Contributions
- Backend development and integration
- SQL database connectivity
- QR-based order lookup integration
- Fetching order details using an order ID or QR code

## Project Information
- **Language:** Java
- **Project Type:** Academic Team Project
- **Institution:** MIT World Peace University, Pune
